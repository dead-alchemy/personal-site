# dnicholas.me

David Nicholas's personal website: a Next.js site with a homepage, an "About Me" page, a resume page, and a blog.

## Development

- `yarn dev` — start the local dev server
- `yarn build` — production build
- `yarn start` — serve the production build
- `yarn lint` — run ESLint
